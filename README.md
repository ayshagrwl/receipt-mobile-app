# OM MARKETING — Receipt Lookup

Mobile-friendly invoice search and payment app hosted on GitHub Pages.

## How it works
- **Frontend**: `index.html` — hosted on GitHub Pages (this repo)
- **Backend**: `Code.gs` — Google Apps Script Web App connected to Google Sheet

## Features
- 🔢 Search by Invoice Number (partial match, e.g. last 4–5 digits)
- 👤 Search by Customer Name — shows full list with dates, amounts, pending balance
- 💰 Record Cash or Bank payments (partial payments supported)
- ✅ Auto-marks invoice as PAID when outstanding hits zero
- 📱 Mobile-first design, works in any browser
